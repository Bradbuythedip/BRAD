📋 HOW TO ADD API KEYS (3 Methods):

METHOD 1: Config File (Recommended)
───────────────────────────────────

1. Get Twitter API keys:
   • Go to https://developer.twitter.com/
   • Create account and app
   • Set "Read and Write" permissions
   • Generate: API Key, API Secret, Access Token, Access Token Secret, Bearer Token

2. Create config file:
   cd Ouroboros Loop
   cp bot/config.example.json bot/config.json
   chmod 600 bot/config.json

3. Edit config.json:
   nano bot/config.json
   
   {
     "simulation_mode": false,
     "twitter_api": {
       "api_key": "YOUR_KEY_HERE",
       "api_secret": "YOUR_SECRET_HERE",
       "access_token": "YOUR_TOKEN_HERE",
       "access_token_secret": "YOUR_TOKEN_SECRET_HERE",
       "bearer_token": "YOUR_BEARER_HERE"
     },
     "bot_config": {
       "tweet_interval_hours": 2,
       "max_tweets_per_day": 12
     }
   }

4. Run bot:
   python3 bot/ouroboros_bot.py

METHOD 2: Environment Variables
─────────────────────────────────

1. Get API keys (same as above)

2. Set environment variables:
   export TWITTER_API_KEY="your_key"
   export TWITTER_API_SECRET="your_secret"
   export TWITTER_ACCESS_TOKEN="your_token"
   export TWITTER_ACCESS_TOKEN_SECRET="your_token_secret"
   export TWITTER_BEARER_TOKEN="your_bearer"

3. Run bot:
   python3 bot/ouroboros_bot.py

4. Make permanent (optional):
   echo 'export TWITTER_API_KEY="your_key"' >> ~/.bashrc
   echo 'export TWITTER_API_SECRET="your_secret"' >> ~/.bashrc
   # ... etc
   source ~/.bashrc

METHOD 3: .env File (Docker)
─────────────────────────────

1. Get API keys (same as above)

2. Create .env file:
   cp .env.example .env
   nano .env
   
   TWITTER_API_KEY=your_key
   TWITTER_API_SECRET=your_secret
   TWITTER_ACCESS_TOKEN=your_token
   TWITTER_ACCESS_TOKEN_SECRET=your_token_secret
   TWITTER_BEARER_TOKEN=your_bearer

3. Run with docker-compose:
   docker-compose up -d

⚡ QUICK DEPLOY (5 Minutes):

STEP 1: Clone & Setup
────────────────────
ssh your-server
git clone https://github.com/Ouroborosbuythedip/Ouroboros-Loop.git
cd Ouroboros Loop
./setup.sh

STEP 2: Add API Keys
───────────────────
cp bot/config.example.json bot/config.json
chmod 600 bot/config.json
nano bot/config.json
# Paste your API keys, save

STEP 3: Test
───────────
python3 bot/ouroboros_bot.py
# Should see tweets printed (simulation mode first)

STEP 4: Go Live
──────────────
# Edit config.json, set "simulation_mode": false
python3 bot/ouroboros_bot.py
# Now posting to Twitter!

STEP 5: Production (Optional)
─────────────────────────────
# systemd (auto-restart, runs on boot)
sudo cp ouroboros-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/ouroboros-bot.service  # Edit paths
sudo systemctl daemon-reload
sudo systemctl enable ouroboros-bot
sudo systemctl start ouroboros-bot

# OR Docker
docker build -t ouroboros-bot .
docker run -d --name ouroboros-bot --restart unless-stopped \
  -v $(pwd)/bot/config.json:/app/bot/config.json:ro \
  ouroboros-bot

# OR docker-compose
docker-compose up -d
